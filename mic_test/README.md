# Тестирование микрофона с постоянной транскрипцией

Этот проект реализует постоянное прослушивание микрофона с возможностью активации по ключевому слову "джарвис".

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Установите модель Vosk для русского языка:
```bash
chmod +x download_model.sh
./download_model.sh
```

## Использование

Запустите скрипт:
```bash
npm start
```

## Как это работает

1. Скрипт постоянно слушает микрофон
2. Когда вы произносите слово "джарвис", активируется режим сбора запроса
3. После паузы в 1 секунду после окончания речи, собранный запрос выводится в консоль
4. Система снова переходит в режим ожидания ключевого слова

## Требования

- Node.js
- Микрофон
- Доступ к интернету (только для первоначальной установки модели)
